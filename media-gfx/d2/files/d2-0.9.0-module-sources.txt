The archive contains a go-mod/ module source/cache tree. For each module
and version below, extracted source is at:
  go-mod/<escaped-module-path>@<version>/
and the corresponding normalized source ZIP and origin metadata are at:
  go-mod/cache/download/<escaped-module-path>/@v/<version>.zip
  go-mod/cache/download/<escaped-module-path>/@v/<version>.info
The .ziphash sidecar and D2's go.sum identify Go module content checksums.
Go module escaping replaces an uppercase letter with ! followed by its
lowercase form, for example PuerkitoBio becomes !puerkito!bio.

Normalized module source archives can also be obtained from the public Go
module proxy using the escaped module path and exact version:
  https://proxy.golang.org/<escaped-module-path>/@v/<version>.zip
These are Go module source archives, not necessarily complete VCS checkouts.
The .info Origin fields, where present, identify the upstream repository
and commit. This index lists the native CLI's 30 external modules; the
archive additionally contains modules needed only by the root/test closure.
